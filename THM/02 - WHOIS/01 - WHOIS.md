- O whois é um protocolo de consulta e resposta que funciona para acessar informações armazenadas sobre domínios.
- Servidores WHOIS escutam a porta 43.

# Objetivos

## Infraestrutura de Rede

- Informações como servidores DNS entre outros
## Engenharia Social ou Phishing

- Utilizando infomações como nomes, emails e telefones.
# Informações Relevantes

| Item                         | Descrição                                                                              |
| ---------------------------- | -------------------------------------------------------------------------------------- |
| Domain Name                  | O própio nome de domínio                                                               |
| Creation and Expiration date | Quando o domínio foi criado e quando ele vai expirar                                   |
| Register                     | A empresa onde o domínio foi registrado                                                |
| Registrant Contact           | Pessoa ou empresa que registrou do domínio                                             |
| Administrative Contact       | Responsável pela gestão do domínio                                                     |
| Technical Contact            | Responsável pela parte técnica do domínio                                              |
| Name Servers                 | Servidores DNS                                                                         |
| Domain Status                | Alterações não permitidas do lado do cliente e do servidor, indica enfase na segurança |
