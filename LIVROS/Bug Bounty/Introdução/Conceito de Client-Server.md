O navegador depende da internet para encaminhar mensagens. Essas mensagens são chamadas de pacotes. Os pacotes incluem os dados que desejam ser enviados e informações sobre a origem e o destino.

Todos os computadores da internet possuem um endereço para poderem fazer o envio e o recebimento de pacotes, alguns computadores aceitam apenas certos tipos de pacotes e outros aceitam apenas pacotes de uma lista restrita de computadores.

```
Cliente -> Inicia a conexão com o Servidor
```

```
Servidor -> Responde a solicitação do cliente
```
