- O Network Mapper (Nmap) é uma ferramenta utilizada para analise de rede e auditorias de segurança
- Pode enumerar redes identificando hosts disponíveis, sistemas operacionais, serviços e suas versões, aplicativos, filtros de pacotes, firewalls, IDS e etc.

# Arquitetura do Nmap

Dentre os diferentes tipos de scan que o Nmap oferece é possível classificar em:
- Descoberta de hosts
- Enumeração de portas
- Enumeração de serviços
- Detecção de OS
- NSE

## Sintaxe

```
nmap <tipo do scan> <opções> <alvo>
```
