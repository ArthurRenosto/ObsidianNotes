- Diretório padronizado
- Localizado no document root
- centraliza metadados como serviços, arquivos de configuração, protocolos etc

# Funcionamento

| URI                               | Descrição                                                                           |
| --------------------------------- | ----------------------------------------------------------------------------------- |
| /.well-known/security.txt         | Informações de contato para pesquisadores de segurança                              |
| /.well-known/change-password      | URL padrão para redirecionamento dos usuários para uma página de alteração de senha |
| /.well-known/openid-configuration | Detalhes de configuração para o OpenID Connect                                      |
| /.well-known/assetlinks.json      | Propriedade de arquivos digitais associados a um domínio                            |
| /.well-known/mta-sts.txt          | Política para MTA-STS                                                               |
Existem muitas outras
