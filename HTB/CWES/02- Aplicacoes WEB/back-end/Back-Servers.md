# hardware
O servidor de back-end contém todo o hardware necessário. Os recursos de energia e desempenho deste hardware determinam o quão estável e responsivo o aplicativo da Web será. como discutido anteriormente no `Architecture`seção, muitas arquiteturas, especialmente para enormes aplicações web, são projetados para distribuir sua carga sobre muitos servidores back-end que coletivamente trabalham juntos para executar as mesmas tarefas e entregar o aplicativo web para o usuário final. Os aplicativos da Web não precisam ser executados diretamente em um único servidor back-end, mas podem utilizar data centers e serviços de hospedagem na nuvem que fornecem hosts virtuais para o aplicativo da Web.
