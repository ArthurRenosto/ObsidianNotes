# Estrutura HTML

```html
<!DOCTYPE html>
<html>
    <head>
        <title>Page Title</title>
    </head>
    <body>
        <h1>A Heading</h1>
        <p>A Paragraph</p>
    </body>
</html>
```

```
<head> contem elementos que nao sao empressos na pagina, como titulo da pagina <head> 

<body> inclui os elementos principais da pagina

<style>Inclui codigo css na pagina

<script> inclui codigo JS na pagina
```

cada um destes elementos e chamado de DOM (Document Object Model)

Tipos de DOM

Core DOM -> padrao para todo documento, mostra ao navegador como acessar e modificar qualquer estrutura de arvore

XML DOM -> dom para XML

HMTL DOM -> DOM para HTMLs
