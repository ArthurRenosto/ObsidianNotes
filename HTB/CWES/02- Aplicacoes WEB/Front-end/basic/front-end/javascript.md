JS e geralmente usado no front end para ser executado pelo navegador

o NodeJS pode ser usado para desenvolvimento back end com JS

### exemplo 1
<script> console.log("hello") </script>

as tags de script acima sao usadas para inserir codigo JS no HTML da pagina, geralmente utilizadas em pequenos scripts

### exemplo 2

<script src="./script.js"></script>

o navegador faz o download do codigo JS que esta em um arquivo separado, e no codigo temos apenas a referencia

o src significa source, ele diz que o navegador deve carregar o arquivo seguinte, e em seguida, passamos o caminho do arquivo
