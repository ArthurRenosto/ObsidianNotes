- Temos muitas redes LAN conectadas a internet, porém nem todas são residenciais. Então surge a necessidade de classificar essas redes conforme o tamanho delas.
### SAN (Storage Area Network ou Rede de área de armazenamento) 
Uma rede dedicada para armazenamento de arquivos como em data centers.
### PAN (Personal Area Network/Rede de área pessoal) 
São redes bem pequenas para dispositivos de curto alcance como por exemplo as redes bluetooth.
### LAN (Local Area Network/Rede de Área Local) 
É uma rede local que abrange um espaço pequeno como por exemplo, escolas, empresas ou uma rede doméstica.
### WLAN (Wireless Local Area Network/Rede Local sem fio)
É uma rede de mesmo tamanho da LAN, porém que usufrui de tecnologias sem fio para se comunicar.
### MAN (Metropolitan Area Network ou Rede metropolitana) 
Uma rede que abrange uma cidade.
### WMAN (Wireless Metropolitan Area Network) 
Uma rede de mesmo tamanho de uma MAN, porém utilizando tecnologias sem fio.
### WAN (Wide Area Network ou Rede de área abrangente)
Uma rede que consegue abranger uma área como um país ou até mesmo um continente.
### WWAN (Wireless Wide Area Network ou Redes de longa distância sem fio) 
É uma rede de mesmo tamanho de uma WAN, porém utilizando tecnologias sem fio.
### GAN (Global Area Network ou Rede de Área Global)
É uma rede que abrange o mundo inteiro, como exemplo, temos a própria internet.
