# Via Rádio

- A Internet via rádio depende do sinal transmitido por torres conhecidas como POPs (Point of Presence/Pontos de Presença)

![[Pasted image 20260125134430.png]]

- Após uma das torres receber o sinal ela pode repassar para outra torre, para assim ser transmitida para as residências.

![[Pasted image 20260125134835.png]]

- Cada local que recebe o sinal, possui um receptor para receber as informações.
- E cada residência também possui um conversor de rádio frequência para dados.

# Via Fibra

- Cabos compostos por feixes de vidro, revestidos por plástico reflexivo e isolante.
