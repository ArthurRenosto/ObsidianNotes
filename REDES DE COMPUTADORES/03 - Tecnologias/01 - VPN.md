- Virtual Private Network.
- Atua como um "túnel" criptografado entre o client e o server vpn.
- Conexão estabelecida sobre uma infraestrutura compartilhada, usando tecnologias de tunelamento e criptografia para manter os dados trafegados seguros e isolados.
- Garante a confidencialidade, autenticação e integridade

# Protocolos utilizados

- L2TP
- LF2
- PPTP
- SSL/TLS
- DTLS
- IPsec

# Funcionamento

 - Client conecta-se a um servidor vpn através de um túnel criptografado
 - Os pacotes encaminhados pelo client chegam ao server vpn e são reenviados para o host de destino a partir dele.
 - Os pacotes que devem ser enviados ao client retornam através do servidor vpn para serem encaminhados através do túnel criptografado.
