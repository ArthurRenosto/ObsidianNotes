O sistema de arquivos atual do win é o NTFS (New Technology File System), antecedente a ele, havia o FAT16/FAT32 (Tabela de alocação de arquivos) e HPFS (Sistema de arquivos de alto desempenho). 

Hoje em dia é possivel ver partições FAT sendo usados em pendrives, cartões MicroSD, etc.

O NTFS é conhecido como sistema de arquivos de journaling, em caso de falha, as pastas e arquivos podem se reparar automaticamente utilizando de informações de log.

https://learn.microsoft.com/en-us/troubleshoot/windows-client/backup-and-storage/fat-hpfs-and-ntfs-file-systems
