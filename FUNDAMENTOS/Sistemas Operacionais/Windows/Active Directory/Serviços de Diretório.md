Um serviço de diretório pode ser associado á uma biblioteca, onde tudo fica armazenado e cadastrado de modo que disponha dos dados de maneira fácil e acessível para os usuários.

Os serviços de Diretórios armazenam dados, usuários, senhas, grupos ao qual o usuário pertence, entre muitas outras informações.

Algumas opções:

Open Ldap para sistemas open souce.

EDirectory para sistemas novel.

Active Directory para sistemas microsoft.
