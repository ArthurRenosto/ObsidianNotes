# Diferença

- Terminal -> Interface que aparece para o usuário.
- Shell -> Interpretador de comandos.
# Caracteristicas

- Tudo que é feito atráves da GUI pode ser feito no shell, porém abrindo a possibilidade de interagir com programas e processos para obter mais informações e permitindo uma maior facilidade na automação de tarefas.
- O shell mais usado no Linux é o Bourne-Again Shell(BASH), e faz parte do projeto GNU.
