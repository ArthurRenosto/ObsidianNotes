Terminal -> interface que aparece para nós 
Shell -> interpretador de comandos, interpreta comandos como ls e lista os diretorios

O shell mais usado no Linux é o Bourne-Again Shell(BASH), e faz parte do projeto GNU. Tudo o que fazemos através da GUI podemos fazer com a casca. O shell nos dá muito mais possibilidades de interagir com programas e processos para obter informações mais rapidamente. Além disso, muitos processos podem ser facilmente automatizados com scripts menores ou maiores que facilitam muito o trabalho manual.
